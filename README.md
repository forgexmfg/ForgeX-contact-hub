# FORGEX Engineering & Manufacturing Solutions

A responsive FORGEX landing page for engineering and digital manufacturing, with a featured Dejavu Decor brand section and a project inquiry form.

## Files

- `index.html` contains the page sections, navigation, and RFQ form behavior.
- `styles.css` contains the responsive FORGEX visual system and brand treatments.
- `assets/7.png` is the supplied FORGEX services poster; local logo and manufacturing image crops are derived from it.
- `assets/logo.svg` is the original supplied FORGEX logo artwork.

The page references the exact Dejavu logo at `assets/dejavu-logo.png`. Add the supplied logo image at that path to display it without modification.

Open `index.html` in a browser to preview the page. Google Fonts, Font Awesome, and the decorative Dejavu photography load from external services.
